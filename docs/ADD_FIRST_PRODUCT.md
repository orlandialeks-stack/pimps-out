# Adding Your First Product — Step by Step

No code needed. About 3 minutes per product.

1. **Log in to the admin dashboard** — go to `/admin` on your site and sign in with your admin email and password.
2. **Create a category first** (optional but recommended): Products → New Product → next to the Category dropdown press **+** and type e.g. `Hoodies`. Do the same for a Collection, e.g. `Collection 001`.
3. **Basics**: enter the product name, description, and price in EUR (your range: €50–€150). Add a sale price only if it's discounted.
4. **Photographs**: click the dashed UPLOAD tile and select one or more product photos (JPG/PNG/WEBP). The first image becomes the cover. Hover a photo to remove it.
5. **Variants**: press **ADD VARIANT** for each size/colour combination. Fill size (e.g. `S`, `M`, `L`, `XL` — any label works), colour name, colour swatch, and stock quantity. Leave SKU blank — it's generated automatically.
6. **Specifications** (all optional, all editable later): material (e.g. `100% heavyweight cotton`), fabric weight in GSM, fit, care instructions, size guide.
7. **Save as Draft** to keep it hidden, then press **PREVIEW** (top right) to see exactly how customers will see it.
8. **Publish**: press **SAVE & PUBLISH** — the product is live on `/shop` instantly. No rebuild, no code.
9. **Feature on the homepage**: in Products, press **FEATURE** on the product row. Press again to unfeature.

## After launch

- **Orders** appear in Admin → Orders. Click a row for details, set status (confirmed → processing → shipped → delivered), paste a tracking code, or issue a refund.
- **Discount codes**: Admin → Discounts — percentage or fixed amount, optional minimum order, expiry date and usage limit.
- **Coming-soon mode**: Admin → Site Content → Coming Soon — toggle off when the collection goes live.
- **Everything else editable**: homepage headlines, hero image, marquee, About page, FAQ, shipping policy, contact email, social links — Admin → Site Content.
